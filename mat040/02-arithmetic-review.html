Number Sets

In mathematics, a collection of numbers is called a set. For the beginning of this class we will only be concerned with two kinds of number sets.

Counting numbers (or natural numbers): positive numbers without fractions or decimals.

{1,2,3,…}\{1,2,3,\ldots\}{1,2,3,…}

Whole numbers (counting numbers and 000):

{0,1,2,3,…}\{0,1,2,3,\ldots\}{0,1,2,3,…}

Curly brackets { }\{\ \}{ } are used in math to group together numbers in a set. An ellipsis …\ldots… means “and so on”, meaning the numbers continue.

We can also denote a set with a number line: a straight line with equally spaced markings. Like the ellipsis, the arrow indicates the numbers continue.

Exponents

Sometimes we need to multiply a number, and sometimes we need to multiply the same number multiple times. Clever mathematicians have created a simple way to denote this, called exponents.

If we want to multiply the number 222 four times, instead of writing 2×2×2×22\times2\times2\times22×2×2×2 we can simplify it to 242^424. The way we would read this out loud is “two to the fourth power”. In this case 444 is called the exponent and 222 is called the base.

Base — the number being multiplied.
Exponent — the number of times the base is being multiplied.

Written like:  abase ⁣ bexponent\text{Written like: }\ \underset{\text{base}}{a}\!{}^{\,\overset{\text{exponent}}{b}}Written like:  basea​bexponent

Order of Operations

Before we can specify an order, let’s discuss what we mean by operation.

An operation is something we do to a number or numbers. For example addition +++, subtraction −-−, multiplication ⋅\cdot⋅, division ÷\div÷, as well as grouping ( )(\ )( ) and [ ][\ ][ ].

Does order really matter? Consider the expression 4+5⋅24+5\cdot24+5⋅2. What answer do we get if we start with 4+54+54+5 and then multiply by 222? 4+5=94+5=94+5=9 and 9⋅2=189\cdot2=189⋅2=18. Now what happens if we do 5⋅25\cdot25⋅2 first and then add 444? 5⋅2=105\cdot2=105⋅2=10 and 10+4=1410+4=1410+4=14. We have two different answers for the same expression depending on the order we solve the parts, so we can confidently say order matters.

In math there is a specific order that we solve the operations in an expression. We remember it as PEMDAS:

Multiplication / Division (moving from left to right)
Addition / Subtraction (moving from left to right)

Negative Numbers and Order Relations

Say you have $20\$20$20 in a bank account and you draw $30\$30$30 from it. How much money will you have in your bank account? −$10-\$10−$10. When you subtract a larger number from a smaller number the result is negative.

Negative numbers are numbers below zero. They can be represented on a number line. The set of numbers {…,−3,−2,−1,0,1,2,3,…}\{\ldots,-3,-2,-1,0,1,2,3,\ldots\}{…,−3,−2,−1,0,1,2,3,…} is called the integers. Negative and positive numbers are inverses of each other.

A number to the left of another number is said to be less than. 111 is less than 222 (1<2)(1<2)(1<2). −5-5−5 is less than −3-3−3 (−5<−3)(-5<-3)(−5<−3). A number to the right of another is greater than. 333 is greater than 222 (3>2)(3>2)(3>2). −1-1−1 is greater than −2-2−2 (−1>−2)(-1>-2)(−1>−2).

So if aaa is greater than bbb we write a>ba>ba>b, and if aaa is less than bbb we write a<ba<ba<b. The further a negative number is from zero, the lesser it is.

Addition

For any two numbers aaa and bbb, the sum is a+ba+ba+b.

Properties of Addition

Commutative property. If aaa and bbb are any two numbers then

a+b=b+aa+b=b+aa+b=b+a

In other words, changing the order of two numbers in a sum doesn’t change the result.
Associative property. If aaa, bbb and ccc are any three numbers then

(a+b)+c=a+(b+c)(a+b)+c=a+(b+c)(a+b)+c=a+(b+c)

In other words, changing the grouping of three numbers doesn’t change the result.
Addition property of 000. If aaa is any number then

a+0=aand0+a=aa+0=a\qquad\text{and}\qquad0+a=aa+0=aand0+a=a

Adding 000 to any number leaves that number unchanged.

Subtraction

The difference of two numbers aaa and bbb is a−ba-ba−b. Subtraction is the same as adding the opposite:

a−b=a+(−b)a-b=a+(-b)a−b=a+(−b)

For any three numbers aaa, bbb, ccc: if a−b=ca-b=ca−b=c then b+c=ab+c=ab+c=a.

For example, if 8−3=58-3=58−3=5 then 3+5=83+5=83+5=8.

If we have any two numbers aaa and bbb and we multiply them, the result is called the product.

Summary

I. Number sets. Counting numbers {1,2,3,…}\{1,2,3,\ldots\}{1,2,3,…} and whole numbers {0,1,2,3,…}\{0,1,2,3,\ldots\}{0,1,2,3,…}.

II. Order of operations. To simplify a mathematical expression:

  1. Begin with expressions inside parentheses ( )(\ )( ) [ ][\ ][ ].

  2. Evaluate exponents.

  3. Multiplication and division from left to right.

  4. Addition and subtraction from left to right.

III. Exponents. The base is the number being multiplied and the exponent is the number of times it is being multiplied. a0=1a^0=1a0=1 and a1=aa^1=aa1=a.

IV. Absolute value. The distance from 000 on the number line. It is never negative.

V. Addition and multiplication.

  • Commutative property: of addition a+b=b+aa+b=b+aa+b=b+a, of multiplication a⋅b=b⋅aa\cdot b=b\cdot aa⋅b=b⋅a.

  • Associative property: of addition (a+b)+c=a+(b+c)(a+b)+c=a+(b+c)(a+b)+c=a+(b+c), of multiplication (a⋅b)⋅c=a⋅(b⋅c)(a\cdot b)\cdot c=a\cdot(b\cdot c)(a⋅b)⋅c=a⋅(b⋅c).

  • Distributive property: a(b+c)=ab+aca(b+c)=ab+aca(b+c)=ab+ac.

VI. Addition of positive and negative numbers. For the same sign, add them: a+ba+ba+b and (−a)+(−b)=−(a+b)(-a)+(-b)=-(a+b)(−a)+(−b)=−(a+b). For opposite signs, subtract: −a+b=−(a−b)-a+b=-(a-b)−a+b=−(a−b) and a+(−b)=a−ba+(-b)=a-ba+(−b)=a−b.
