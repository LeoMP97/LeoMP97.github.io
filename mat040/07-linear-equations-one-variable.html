Linear Equations in One Variable

Examples of linear equations in one variable:

3x+2=177a+4=3a−23x+2=17\qquad\qquad7a+4=3a-23x+2=177a+4=3a−2

Steps to solve a linear equation in one variable
Step 1. Simplify each side of the equation as much as possible.
Step 2. Use the addition property of equality to get all the variable terms on one side and the constants on the other, then combine like terms.
Step 3. Use the multiplication property to get the variable by itself.
Step 4. Check your solution.

The Addition Property of Equality

Two angles AAA and BBB that together make a right angle satisfy

A+B=90∘.A+B=90^\circ.A+B=90∘.

So if A=30∘A=30^\circA=30∘ then 30∘+B=90∘30^\circ+B=90^\circ30∘+B=90∘, and B=90∘−30∘=60∘B=90^\circ-30^\circ=60^\circB=90∘−30∘=60∘.

To remove a number that is being added in an equation, we must subtract it, and to keep the equation balanced it must be done to both sides. Note: subtracting a negative number is the same as adding the opposite.

Addition Property. If A=BA=BA=B then A+C=B+CA+C=B+CA+C=B+C.
