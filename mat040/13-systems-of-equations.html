Is an Ordered Pair a Solution?

When two or more linear equations are grouped together, they form a system of linear equations.

We focus on systems of two linear equations in two unknowns. We use a brace to show the equations are grouped together. For example:

{2x+y=7x−2y=6\begin{cases}2x+y=7\\x-2y=6\end{cases}{2x+y=7x−2y=6​

A linear equation in two variables, like 2x+y=72x+y=72x+y=7, has infinitely many solutions. Its graph is a line, and every point on the line is a solution to the equation, and every solution is a point on the line. To solve a system we find the ordered pairs (x,y)(x,y)(x,y) that make both equations true.

Solutions of a system of equations are the values of the variables that make all the equations true. A solution of a system of two linear equations is represented by an ordered pair (x,y)(x,y)(x,y).

To determine if an ordered pair is a solution, substitute the values into both equations. If the pair makes both equations true, it is a solution of the system. Consider the system

{3x−y=7x−2y=4\begin{cases}3x-y=7\\x-2y=4\end{cases}{3x−y=7x−2y=4​

Is (2,−1)(2,-1)(2,−1) a solution? Substitute x=2x=2x=2 and y=−1y=-1y=−1:

3(2)−(−1)=6+1=7 ✓2−2(−1)=2+2=4 ✓3(2)-(-1)=6+1=7\ \checkmark\qquad\qquad2-2(-1)=2+2=4\ \checkmark3(2)−(−1)=6+1=7 ✓2−2(−1)=2+2=4 ✓

Both are true, so (2,−1)(2,-1)(2,−1) is a solution. Is (3,2)(3,2)(3,2) a solution? Substitute x=3x=3x=3 and y=2y=2y=2:

3(3)−2=7 ✓3−2(2)=−1≠4 ×3(3)-2=7\ \checkmark\qquad\qquad3-2(2)=-1\neq4\ \times3(3)−2=7 ✓3−2(2)=−1=4 ×

It made one equation true but the other false, so (3,2)(3,2)(3,2) is not a solution.

Types of Systems

It is possible for a system to have no solution.

A consistent system of equations is a system with at least one solution.
An inconsistent system of equations is a system with no solution.

We also describe the equations in a system as independent or dependent.

Two equations are independent if they have different solutions.
Two equations are dependent if all the solutions of one equation are also solutions of the other equation.

How to solve a system of equations by substitution.

Step 2. Substitute the expression from Step 1 into the other equation.

Solving Systems of Equations by Elimination

Substitution works well when we can easily solve one equation for a variable without too many fractions. The second method, elimination, is based on the Addition Property of Equality: when you add the same quantity to both sides of an equation you still have equality. We extend it to say that adding equal quantities to both sides keeps the equation equal.

For any expressions a,b,c,da,b,c,da,b,c,d: if a=ba=ba=b and c=dc=dc=d then a+c=b+da+c=b+da+c=b+d.

To solve a system by elimination, start with both equations in standard form, Ax+By=CAx+By=CAx+By=C. Then decide which variable is easiest to eliminate by making its coefficients opposites, so that adding the equations eliminates that variable. For example,

3x+y=5+  2x−y=05x+y=5\begin{array}{r}3x+y=5\\+\ \ 2x-y=0\\\hline5x\phantom{{}+y}=5\end{array}3x+y=5+  2x−y=05x+y=5​​

The yyy’s add to zero and we have one equation with one variable. Let’s try

{x+4y=22x+5y=−2\begin{cases}x+4y=2\\2x+5y=-2\end{cases}{x+4y=22x+5y=−2​

We don’t see a variable we can eliminate by adding yet. But if we multiply the first equation by −2-2−2 (every term!), the coefficients of xxx are opposites:

−2x−8y=−4+  2x+5y=−2−3y=−6\begin{array}{r}-2x-8y=-4\\+\ \ 2x+5y=-2\\\hline-3y=-6\end{array}−2x−8y=−4+  2x+5y=−2−3y=−6​​

so y=2y=2y=2. Substituting into x+4y=2x+4y=2x+4y=2 gives x+8=2x+8=2x+8=2, so x=−6x=-6x=−6. The solution is (−6,2)(-6,2)(−6,2). Check: 2(−6)+5(2)=−12+10=−2✓2(-6)+5(2)=-12+10=-2\checkmark2(−6)+5(2)=−12+10=−2✓.

How to solve a system of equations by elimination.
Step 1. Write both equations in standard form. If any coefficients are fractions, clear them.
Step 2. Make the coefficients of one variable opposites. Decide which variable you will eliminate, then multiply one or both equations so that the coefficients of that variable are opposites.
Step 3. Add the equations resulting from Step 2 to eliminate one variable.
Step 4. Solve for the remaining variable.
Step 5. Substitute the solution from Step 4 into one of the original equations. Then solve for the other variable.
Step 6. Write the solution as an ordered pair.
Step 7. Check that the ordered pair is a solution to both original equations.
