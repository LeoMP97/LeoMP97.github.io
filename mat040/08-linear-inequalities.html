Graph Inequalities on the Number Line

Recall that a solution of an equation is a value of the variable that makes a true statement when substituted into the equation. What about the solution of an inequality? What number would make x>3x>3x>3 true? xxx could be 444, but also 555, 202020, or even 3.0013.0013.001. Any number greater than 333 is a solution.

We show the solutions of x>3x>3x>3 on the number line by shading all the numbers to the right of 333. Because 333 itself is not a solution, we put an open parenthesis at 333.

x>3x>3x>3  

For x≥3x\geq3x≥3 we need to show that 333 is a solution too, so we put a bracket at 333.

x≥3x\geq3x≥3  

The parenthesis ((( shows that the endpoint of the inequality is not included. The bracket [[[ shows that the endpoint is included.

Interval Notation

We can also write inequalities in interval notation. The inequality x>3x>3x>3 means all numbers greater than 333. There is no upper end, so we write (3,∞)(3,\infty)(3,∞). The symbol ∞\infty∞ is read “infinity”; it is not an actual number. The inequality x≤1x\leq1x≤1 has no lower end, so we write (−∞,1](-\infty,1](−∞,1], where −∞-\infty−∞ is read “negative infinity”.

The parenthesis or bracket in interval notation matches the symbol at the endpoint of the arrow.

Infinity always gets a parenthesis, since it is not a number we can reach.

The Addition and Subtraction Properties of Inequality

The Subtraction and Addition Properties of Equality say that if two quantities are equal, adding or subtracting the same amount from both gives equal results. Similar properties hold for inequalities. For example, −4<2-4<2−4<2. If we subtract 555 from both sides we get −9-9−9 and −3-3−3, and −9<−3-9<-3−9<−3. The inequality sign stayed the same.

Properties of Inequality. For any numbers aaa, bbb and ccc:

Subtraction PropertyAddition Property
if a<ba<ba<b then a−c<b−ca-c<b-ca−c<b−cif a<ba<ba<b then a+c<b+ca+c<b+ca+c<b+c
if a>ba>ba>b then a−c>b−ca-c>b-ca−c>b−cif a>ba>ba>b then a+c>b+ca+c>b+ca+c>b+c

We use these properties to solve inequalities, taking the same steps we used to solve equations. For x+5>9x+5>9x+5>9:

x+5>9 → x+5−5>9−5 → x>4x+5>9\ \to\ x+5-5>9-5\ \to\ x>4x+5>9 → x+5−5>9−5 → x>4

Any number greater than 444 is a solution.

The Division and Multiplication Properties of Inequality

The Division and Multiplication Properties of Equality say that if two quantities are equal, dividing or multiplying both by the same amount (not dividing by 000) gives equal results. What happens to an inequality?

Start with 10<1510<1510<15. If we divide both sides by 555 we get 2<32<32<3. If we multiply both sides by 555 we get 50<7550<7550<75. The sign stayed the same.

Now what if we divide or multiply by a negative number? Dividing 10<1510<1510<15 by −5-5−5 gives −2-2−2 and −3-3−3, and −2>−3-2>-3−2>−3. Multiplying both sides by −5-5−5 gives −50-50−50 and −75-75−75, and −50>−75-50>-75−50>−75. The inequality sign reversed.

if a<b and c>0, then ac<bc and ac<bcif a>b and c>0, then ac>bc and ac>bcif a<b and c<0, then ac>bc and ac>bcif a>b and c<0, then ac<bc and ac<bc\begin{align*} \text{if }a<b\text{ and }c>0,&\text{ then }\frac ac<\frac bc\text{ and }ac<bc\\ \text{if }a>b\text{ and }c>0,&\text{ then }\frac ac>\frac bc\text{ and }ac>bc\\ \text{if }a<b\text{ and }c<0,&\text{ then }\frac ac>\frac bc\text{ and }ac>bc\\ \text{if }a>b\text{ and }c<0,&\text{ then }\frac ac<\frac bc\text{ and }ac<bc \end{align*}if a<b and c>0,if a>b and c>0,if a<b and c<0,if a>b and c<0,​ then ca​<cb​ and ac<bc then ca​>cb​ and ac>bc then ca​>cb​ and ac>bc then ca​<cb​ and ac<bc​

When we divide or multiply an inequality by a positive number, the inequality stays the same.
When we divide or multiply an inequality by a negative number, the inequality reverses.

Sometimes the variable ends up on the right. We can rewrite the inequality in reverse to put the variable on the left: x>ax>ax>a has the same meaning as a<xa<xa<x. (If Xavier is taller than Alex, then Alex is shorter than Xavier.)

Inequalities That Require Simplification

Most inequalities take more than one step. We follow the same steps we used to solve linear equations, but we pay close attention when multiplying or dividing by a negative number.

Just like some equations are identities and some are contradictions, inequalities may be too. We recognize these when only constants are left as we solve. If the result is a true statement we have an identity (the solution is all real numbers). If the result is a false statement we have a contradiction (there is no solution).
